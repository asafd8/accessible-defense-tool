# Accessible Defense Tool

## The Problem
When a person is physically attacked, the common options are to flee or fight back. For people with physical disabilities (e.g., wheelchair users, people using walkers or crutches), these options are often impossible. This can create a life-threatening trap, especially if no one is around to help.

## The Challenge
Develop a defense tool that is:
1.  **Adaptable:** Must be usable by individuals with varying physical abilities.
2.  **Accessible:** Criteria for eligibility must be established to prevent misuse.
3.  **Environmentally Aware:** Must function in different environments (urban, rural, hot, cold, flat, mountainous).
4.  **Non-Lethal:** Must neutralize the attacker without causing unnecessary harm.
5.  **Legally Compliant:** Must adhere to local laws and regulations where it is sold.

*This may require a series of products, not just one.*
